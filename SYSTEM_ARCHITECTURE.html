⏱️ Request Timing Breakdown

Frontend Processing (Steps 1-4): ~50-100ms User action, validation, request preparation
Network Transit (Step 5): ~10-500ms (depends on network) HTTP request travels to server
Backend Processing (Steps 6-13): ~50-500ms Middleware checks, controller logic, database queries
Response Generation (Steps 14-15): ~20-50ms Format response, send back to client
Frontend Update (Steps 16-18): ~16-100ms Update state, React re-render, DOM update
Total Typical Time: ~200-1200ms (Mostly depends on network and database query complexity)

📊 Database Schema Details

users: System users (Admin, Staff, Cashier, Tenant)
tenants: Tenant profile linked to user account
rental_spaces: Available rental units/offices
contracts: Lease agreements between tenants and spaces
payments: Monthly payment records with status tracking
demand_letters: Overdue notices with calculated interest
notifications: System alerts for all users
chat_messages: Direct messaging between users
audit_logs: Activity tracking for compliance

🔐 Role-Based Access Control (RBAC)

Admin: Full system access, can manage all contracts, payments, tenants, reports, users, and system settings. Can perform all operations.
Staff: Operational access similar to admin but cannot manage user accounts or change system settings. Cannot record payments (cashier-only).
Cashier: Limited to payment operations. Can view and record payments, view demand letters, generate receipts, but cannot create or modify contracts.
Tenant: Very limited access. Can only view their own contracts, payments, download lease agreements, and scan QR codes for contract information.
