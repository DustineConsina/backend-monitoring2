🎨 Frontend Structure (Next.js)

1
App Router: Next.js App directory with route segments
2
Contexts: AuthContext for user/auth state
3
Components: Reusable UI components (Tables, Forms, Charts)
4
Pages: Role-based page layouts
5
Rendering: Client-side rendered content

📋 Page Hierarchy

1
/dashboard: Main layout wrapper
2
/dashboard/contracts: List & manage contracts
3
/dashboard/payments: Payment management
4

5

📌 Key Content Elements:
  • Navigation: Dynamic based on user role
  • Tables: Sortable, filterable data displays
  • Forms: Modal or page-based forms for CRUD operations
  • Charts: Recharts for statistics visualization
  • Notifications: Toast/Alert messages for user feedback

3-4

5-6
Server Processing: Middleware validates request → Route to appropriate controller
7-8
Database Access: Controller uses Model → Execute database query
9-12
Response Creation: Database returns data → Controller formats JSON response
13-15
Frontend Update: Frontend receives response → State updates → UI re-renders

📋 Endpoint Categories & Data Types

📤 Request Data Types

1
JSON Body: Form data in JSON format
2
Query Params: Filters, pagination, sort
3
URL Params: Resource IDs (/:id)
4
Headers: Auth token, Content-Type
5
Files: PDFs, images (multipart/form-data)

📥 Response Data Types

1
JSON Data: Resource records with fields
2
Collections: Arrays of records
3
Pagination: data, current_page, total
4
Relationships: Nested data structures
5
Files: PDF download stream

🔒 Authentication Flow

1
User Login: POST /login with credentials
2
Token Generated: Sanctum creates bearer token
3
Token Storage: Stored in browser localStorage
4
Token Usage: Included in Authorization header
5
Middleware Check: auth:sanctum middleware validates token
